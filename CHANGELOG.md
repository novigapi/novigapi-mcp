## 0.1.0 - 2026-11-15

- First release: stdio MCP server for the Novig API at https://novigapi.com. Keyless tools work with no key; set
  `NOVIGAPI_KEY` for the rest. Not on npm yet; run it from a clone (`node bin/novigapi-mcp.mjs`).
